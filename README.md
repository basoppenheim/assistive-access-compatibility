# Assistive Access App Compatibility

An overview of Assistive Access support across commonly installed iOS apps. Assistive Access is an iOS feature that simplifies the iPhone experience for users with cognitive disabilities, offering a streamlined interface with larger text and buttons. We would have called this repository `awesome-assistive-access` if it wasn't for what we found.

> **Note:** This overview is based on a targeted survey conducted in March 2026. Apps were selected across multiple categories to ensure broad coverage: popular mainstream apps, award-winning indie apps, accessibility-focused tools, apps specifically targeting Assistive Access user groups, and government services. At the time of testing, only one third-party app shipped a dedicated Assistive Access interface.

## What is Assistive Access?

Assistive Access was introduced in iOS 17 and provides a simplified experience with:
- Large text and buttons
- High-contrast visual design
- Streamlined app layouts
- Reduced cognitive load

For more information, see [Apple's Assistive Access documentation](https://support.apple.com/guide/assistive-access-iphone/intro-to-assistive-access-stca73c75dc0/ios).

## Legend

| Symbol | Meaning |
|--------|---------|
| ✅ | Dedicated Assistive Access interface |
| ⚠️ | Partial adjustments, but not designed for Assistive Access users |
| ❌ | No Assistive Access support |

## Contributing

This list is far from complete! If you've tested an app for Assistive Access compatibility, we'd love your help expanding this overview.

### How to contribute

1. **Fork** this repository
2. **Add or update** app entries in the alphabetical table
3. **Submit a pull request** with your changes

### Guidelines

- Test the app yourself in Assistive Access mode before submitting
- Keep the table sorted alphabetically
- Use ✅, ⚠️, or ❌ to indicate the level of support
- Include the app version you tested in your PR description
- If the app has a dedicated Assistive Access interface, please describe shortly what it includes and how it differs from the standard UI. Add a link if there's more information about their Assistive Access implementation online."
- If an app has partial support, describe the limitations in the Notes column
